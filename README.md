# BloodLink Website

A responsive, healthcare-focused marketing website for the BloodLink blood donor discovery app, built using only HTML5, CSS3 and vanilla JavaScript.

## Files

- index.html – landing page
- privacy.html – privacy policy page
- terms.html – terms of service page
- css/style.css – main styling and responsive layout
- js/script.js – navigation, FAQ, form validation, reveal animations and counters
- assets/ – local placeholder SVG assets for branding and app previews

## Notes

The website uses local SVG placeholders in the assets folder so the project works immediately without external image dependencies. Replace the placeholder graphics with product screenshots and brand assets when available.
